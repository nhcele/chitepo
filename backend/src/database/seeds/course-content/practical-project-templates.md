## Submission Guidelines

### Format Requirements
- Font: Arial or Times New Roman, 12pt
- Spacing: 1.5 or Double
- Margins: 1 inch all sides
- Page numbers: Bottom center
- Headers: Include student name and page number

### File Naming Convention
- Format: StudentName_ProjectType_Date.pdf
- Example: TendaiMoyo_DCCActionPlan_2025-11-27.pdf

### Submission Process
1. Save as PDF
2. Upload to course platform
3. Submit before deadline
4. Receive confirmation email
5. Wait for feedback (7-10 working days)

### Late Submission Policy
- 1 day late: -5%
- 2-3 days late: -10%
- 4-7 days late: -20%
- More than 7 days: Requires special permission
